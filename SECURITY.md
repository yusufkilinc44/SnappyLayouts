# Security & Privacy Policy

## Privacy & Local-Only Operation
- **Snappy Layout** operates 100% locally and offline. No telemetry, window titles, screen metrics, or workspace URLs are ever transmitted to external servers.
- All user settings, snap layouts, virtual monitor presets, and workspaces are stored locally in `%AppData%\Snappy Layout\settings.json`.
- When Snappy Layout exits, Windows 11's native `EnableSnapAssistFlyout` and `EnableSnapBar` registry settings are automatically restored to their original values.

## Reporting a Vulnerability
If you discover a security issue or bug, please open an issue in the [GitHub Issues](https://github.com/yusufkilinc44/SnappyLayouts/issues) tracker with reproduction steps and environment details.
